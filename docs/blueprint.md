# **App Name**: InsightBoard AI

## Core Features:

- Interactive KPI Dashboard: Dynamically display various Key Performance Indicator cards, featuring current metrics, percentage changes, and mini-trend visualizations for at-a-glance data insights.
- Navigation Sidebar: A persistent, collapsible sidebar providing clear navigation to different reports, data modules, and tools within the application.
- Personalized Header & Actions: A top header displaying user greetings (e.g., 'Welcome Shivam Pahuja') and contextual quick actions such as viewing the Executive Summary or invoking the AI assistant.
- Real-time Data Integration: Securely fetch and present up-to-date business intelligence metrics and indicators from external backend data sources.
- Ask AI Insights Tool: An integrated conversational AI tool, akin to 'Ask DIVA', enabling users to query specific data points, receive interpretations of complex KPIs, and get predictive insights directly from the dashboard.
- Executive Summary Generator: Leverage AI to automatically synthesize current dashboard data, identifying key trends and critical performance highlights, to generate a concise and actionable executive summary report.

## Style Guidelines:

- A dark theme for professionalism and clarity in data presentation. The background color will be a deep desaturated blue-grey, visually derived from the primary color (approx. HSL: 220, 15%, 10%, converting to RGB hex: #15181C).
- The primary interactive color will be a sophisticated and moderately vibrant blue, suggesting reliability and insight (approx. HSL: 220, 80%, 60%, converting to RGB hex: #529AF5). This will be used for interactive elements and key highlights.
- An analogous accent color in a cool cyan hue will be used for contrasting elements, status indicators, and subtle visual cues to guide user attention (approx. HSL: 190, 90%, 55%, converting to RGB hex: #0AC8F9).
- The 'Inter' sans-serif typeface will be used throughout the application for both headlines and body text. Its neutral, modern, and highly legible design is ideal for presenting data and information effectively.
- Clean, minimalistic line icons with a consistent geometric style will be utilized for navigation, data points, and status indicators to maintain a modern and professional aesthetic.
- A grid-based layout for KPI cards ensures efficient use of space and scannability. A fixed, resizable sidebar will provide access to navigation, complemented by a sticky header for consistent user context and access to global actions.
- Subtle and fluid micro-animations for hover states, data loading, and transitions between dashboard views will enhance user experience without being distracting.
